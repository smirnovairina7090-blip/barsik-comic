Барсик — интерактивный комикс v7

Новое:
- по нажатию на «Сделать Барсика ещё довольнее» включаются звуковые фанфары;
- поверх экрана появляется визуальная анимация фанфар:
  - две трубы вылетают с краёв;
  - вспыхивают лучи;
  - появляется «ТА-ДА-А-АМ!»;
  - разлетаются звёзды и праздничные символы;
- конфетти на самой карточке Барсика осталось.

Откройте index.html в браузере.
